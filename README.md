# 📊 Smart CSV Analytics Dashboard

An intelligent analytics platform that allows users to upload CSV datasets and automatically generate:

- 📈 Smart visualizations
- 🧹 Automated data cleaning
- 📋 Dataset profiling
- 🧠 Smart insights
- 🔥 Correlation analysis
- 📊 Dynamic KPI reports
- ⬇ Downloadable cleaned datasets

---

# 🚀 Features

## ✅ Automated Data Cleaning
- Duplicate row removal
- Missing value handling
- Automatic preprocessing

## ✅ Smart Schema Detection
- Numeric column detection
- Categorical column detection
- Datetime detection

## ✅ Dynamic Visualizations
- Histograms
- Bar Charts
- Pie Charts
- Time-Series Analysis
- Correlation Heatmaps

## ✅ Intelligent Insights Engine
- Outlier detection
- Strong correlation analysis
- Dominant category detection
- Missing value analysis

## ✅ Dataset Profiling
- Memory usage reporting
- Data type summaries
- Missing value percentages
- Dataset structure analysis

# ▶ Run Locally

## 1️⃣ Clone Repository

```bash
git clone YOUR_GITHUB_REPO_LINK
```

---

## 2️⃣ Navigate To Project

```bash
cd smart-csv-analytics-dashboard
```

---

## 3️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux/Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 5️⃣ Run Application

```bash
streamlit run app.py
```
